## Notes (non-blocking; for the historian's documentation pass and future work)

1. **Last-grant removal after a kiki add is refused (prior fix-review note 1, still present, untested).** With a kiki-written `[grant, suffix]`, removing the only grant leaves the orphaned suffix of inherited deny tuples → `protectProjectSurvivors` fails 'Legacy baseline mirror' (empty `derivingAllows` → empty `expectedSuffix` → all inherited denies positional), and suffix entries are themselves refused as inherited. Managed writes never create the orphaned state (the removal is refused first); the escape for a manually orphaned suffix is a manual file edit, which spec §7 places outside the guarantee. Fail-closed, user-visible — README should document it.
2. **Inherited-ask positional acceptance asymmetry (prior fix-review note 2, still present).** Inherited ASK tuples pass anywhere in a project tier (unlike denies); a hand-copied `ask shell git push*` could flip the inherited force-push denies to ask under merged last-match, and `kiki permissions check` reports no conflict. Hand-edit-only (managed writes cannot produce it); document as accepted residual risk alongside the symlink/wrapper limits, or tighten later.
3. **`add` surface is narrower than the validator** (architect note 3): the CLI exposes only `--action read|edit`; `external_directory` /tmp forms remain hand-addable. Intentional; document so users are not surprised.
4. **Global-update path has no pre-write byte precondition** between preflight read and `patchAgents` write (concurrent external edits during `kiki update` are overwritten as at baseline, caught only by post-write verification). The project CLI path — where the plan demanded exact-target TOCTOU — has full byte preconditions; the global path keeps pre-existing behavior and the crash protocol keeps evidence never-stale. Acceptable; not a regression.
5. **Fragment conflict halt on user-appended prose:** text added by the user after the managed fragment makes the next update fail preflight (safe halt, no overwrite). Same for a future fragment v2 (architect note 5). Record as future work (v1→v2 transition story).
6. **Minor dead code:** `ownershipStateDirectory` is exported but unused; `parsePermissionsArgs` is exported without an external consumer. Trivial.
7. **Documentation pending:** README/CHANGELOG (plan Task 4) are deliberately deferred to the historian. They must cover CLI syntax, ownership/drift/bootstrap semantics, the approved selected-entry removal contract, managed-write-only security, the accepted wrapper/symlink LIMITs, and notes 1–3 above.
